# Security Policy

## Supported versions

Security fixes are made to the latest tagged release (`v0.1.x`) and to
`main`.  Older tags do not receive security updates.

## Reporting a vulnerability

**Please do not open a public GitHub issue for security problems.**

Use GitHub's private vulnerability reporting:

1. Go to the repository's **Security** tab → **Report a vulnerability**
   (direct link: <https://github.com/ZengZichao/OpenRelTime/security/advisories/new>).
2. Describe the issue, how to reproduce it, and the affected version or
   commit.

If private reporting is unavailable for any reason, you can reach the
maintainer at **zengzichao@sjtu.edu.cn** (subject: "OpenRelTime security").

## What to expect

- You will receive an acknowledgement as soon as possible.
- Findings are triaged, fixed and released with coordinated disclosure;
  reporters are credited in the release notes unless they prefer otherwise.
- Please allow reasonable time for a fix to be published before any public
  disclosure.
