## Sequence accessions of `example.nwk`

The tree was built from 274 mitochondrial genome sequences (dos Reis et al.
2012, doi:10.1098/rspb.2012.0683).  The per-taxon accession list is **not** part
of this repository: `data/examples/example.nwk` carries only tip labels and
branch lengths, and the R3F provenance it arrived with points at the
publication rather than at a machine-readable accession table, so the raw
sequences are cited through that publication and no accession identifiers are
asserted here beyond what the source data supply.

## CorrScore precision note

`corrtest()` writes its score with `format(score, digits = 5)`, so
`r3f/example_sr0_corrtest.txt` records `score = 0.9996` and
`r3f/example_sr50_corrtest.txt` records `0.99959`. Those are five significant
digits of the reference result, not the result itself. The unrounded doubles are
in `r3f/example_corrtest_full_precision.txt`, obtained by re-sourcing the same
R3F functions with only that print width widened to 17 digits
(`reproduce/golden_r3f_fullprec.R`); the numerical path is untouched.

## Reproducibility of this directory

`Rscript reproduce/golden_r3f.R <project_root> <R3F/R>` was run in the
micromamba environment `r-4.5.3` (R 4.5.3, ape 5.8.1, phangorn 2.11.1, R.utils
2.13.0, FNN 1.1.4.1, RColorBrewer 1.1-3).  Eleven of the twelve files come back
**byte-identical**.  The exception is `example_RRF_timetree.nexus`, whose only
difference is the write-time stamp ape puts in its header line
(`[R-package APE, <day date time year>]`).  Treat that file as value-reproducible
but not byte-reproducible; comparisons against it must ignore the header stamp.
